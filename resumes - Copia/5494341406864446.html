State-Space Modelling of Complex Transmission Networks with Multiple Converter Systems
Descrição: Project funded by RTE (Reseau De Transport DElectricite) France. The project aims developing small-signal, state-space models for multiple HVDC-connected large offshore wind farms. The project is collaboration between research centre (University of Aberdeen, UK), Grid operator (RTE, France), and simulation software developer, (EMTP, Canada). RTE and Europe in general, have ambitious plans for developing large scale offshore wind energy, which will be predominantly connected using MMC (Modular Multilevel Converter) HVDC transmission. In these new systems, the interactions between wind farm converters ad HVDC are becoming of high importance. In particular, the interactions between two HVDC systems are of concern when multiple wind farms are installed in vicinity. The analytical phasor and small-signal dynamic models will bring significant advantages for stability analysis, but they are not available on commercial simulation platforms like EMTP. These analytical models facilitate eigenvalue and parametric studies which are much faster and provide better in-depth stability analysis, than time-domain trial and error simulation. This project will attempt to generalize analytical converter state-space models and their connections to facilitate simple model building for complex systems with many converters. There is only a limited number of converter topologies, and therefore each converter topology can be represented as an object (standard state-space subroutine) with standard inputs and outputs. Also, using subroutines with averaged, linearized time-invariant converter models will eliminate issues with solver speed and robustness. The project will further attempt to connect EMTP graphical platform with state- space code for automation of code generation. A particular challenge will be inherent use of dq frame with analytical models, as EMTP exclusively employs static abc frame for simulation.Ideally, the project will deliver foundations for a new platform utilising state-space average-value model building, which will be attached to EMTP. A user will start with EMTP model and may choose to generate MATLAB state-space code for their system. With state-space code the user will be able to continue analysis on MATLAB, employing parametric studies, or frequency domain study, eigenvalue study or controller design using control toolboxes. In the last design stage, the parameters obtained on MATLAB model can be entered in EMTP model for final verification of performance..

Novas Tecnologias na Aplicação de Chaves Semicondutoras em Temperatura Criogênica para Conversores de Potência
Descrição: O projeto de pesquisa propõe o estudo e desenvolvimento de novas tecnologias para a aplicação de chaves semicondutoras em temperaturas criogênicas, voltadas para conversores de potência. A pesquisa busca explorar os benefícios da criogenia para melhorar os parâmetros de desempenho dessas chaves, como a eficiência e densidade de corrente, utilizando materiais semicondutores avançados, como SiC e GaN. O projeto inclui ensaios experimentais para caracterização das chaves, modelagem computacional em ferramentas como COMSOL e Typhoon HIL, e o desenvolvimento de protótipos de conversores de potência. A crioeletrônica vem sendo apontada como uma das principais direções para a eletrônica de potência devido ao seu vasto potencial de aplicação em setores estratégicos, como o de óleo e gás, a eletrificação do transporte (com destaque para a aviação), a medicina diagnóstica de alta precisão, os sistemas de armazenamento de energia e o acionamento de máquinas elétricas supercondutoras. No geral, as aplicações práticas incluem a utilização desta tecnologia em sistemas críticos que demandam baixo volume e peso para os conversores, possibilitando a obtenção de patentes oriundas de critérios de projetos para este tipo de sistemas. Ao longo do estudo, espera-se validar as melhorias de performance em ambientes criogênicos, otimizar o projeto dos conversores e gerar publicações científicas relevantes..

State-Space Modelling of Complex Transmission Networks with Multiple Converter Systems
Descrição: Project funded by RTE (Reseau De Transport DElectricite) France. The project aims developing small-signal, state-space models for multiple HVDC-connected large offshore wind farms. The project is collaboration between research centre (University of Aberdeen, UK), Grid operator (RTE, France), and simulation software developer, (EMTP, Canada). RTE and Europe in general, have ambitious plans for developing large scale offshore wind energy, which will be predominantly connected using MMC (Modular Multilevel Converter) HVDC transmission. In these new systems, the interactions between wind farm converters ad HVDC are becoming of high importance. In particular, the interactions between two HVDC systems are of concern when multiple wind farms are installed in vicinity. The analytical phasor and small-signal dynamic models will bring significant advantages for stability analysis, but they are not available on commercial simulation platforms like EMTP. These analytical models facilitate eigenvalue and parametric studies which are much faster and provide better in-depth stability analysis, than time-domain trial and error simulation. This project will attempt to generalize analytical converter state-space models and their connections to facilitate simple model building for complex systems with many converters. There is only a limited number of converter topologies, and therefore each converter topology can be represented as an object (standard state-space subroutine) with standard inputs and outputs. Also, using subroutines with averaged, linearized time-invariant converter models will eliminate issues with solver speed and robustness. The project will further attempt to connect EMTP graphical platform with state- space code for automation of code generation. A particular challenge will be inherent use of dq frame with analytical models, as EMTP exclusively employs static abc frame for simulation.Ideally, the project will deliver foundations for a new platform utilising state-space average-value model building, which will be attached to EMTP. A user will start with EMTP model and may choose to generate MATLAB state-space code for their system. With state-space code the user will be able to continue analysis on MATLAB, employing parametric studies, or frequency domain study, eigenvalue study or controller design using control toolboxes. In the last design stage, the parameters obtained on MATLAB model can be entered in EMTP model for final verification of performance..
