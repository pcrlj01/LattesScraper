Projetos de extensão

2009 - 2009
Desenvolvimento de um sistema supervisorio para a monitorização de variaveis fisicas ambientais em um galpão avícola.
Descrição: Desenho de hardware e software para o monitoramento das variáveis físicas ambientais (temperatura, umidade, qualidade do ar e velocidade do vento) envolvidas no processo de mortalidade de frangos em galpões avícolas. Os dados coletados são transmitidos até uma estação base utilizando o padrão IEEE 802.15.4 quem a sua vez transmite os dados até um banco de dados remoto. A visualização dos dados coletados pode ser feita localmente ou remotamente utilizando uma interfase homem-maquina desenvolvida no projeto..
Situação: Concluído; Natureza: Extensão.
Alunos envolvidos: Graduação: (2) / Mestrado acadêmico: (2) / Doutorado: (1) .

Integrantes: Hector Enrique De La Hoz Leon - Coordenador.
