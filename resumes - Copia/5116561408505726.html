2023 - Atual
Signal Processing and Synchronization Algorithms for 6G X-hauling
Descrição: This project proposal targets the continuation of the UFA27 SmartHaul project and the investigation of new research topics. The goal of the current proposal is to further investigate synchronization techniques and signal processing for x-hauling, and start investigations in non-terrestrial networks (NTN), with a focus on issues related to satellite fronthauls (FH) with considerable latency.The proposal is composed of three work packages (WP). The first WP regards synchronism with and without PTP-assisted nodes. The second WP investigates radio signal processing for smart x-hauling, with emphasis on systems incorporating distributed MIMO. The third WP concerns non-terrestrial networks. During the UFA27 project, UFPA investigated synchronization over packet-based networks with partial timing support (PTS). In the current proposal, we aim at expanding the on-going research on IEEE 1588 precision time protocol (PTP) performance in FH networks to include some use cases of assisted PTS (APTS) (see ITU G.8275.2 for details on the nomenclature). Within this expanded scope, the first work package investigates holdover using machine learning, radio-interface based synchronization and radio-centric synchronization architectures. The second WP considers the difficult problem of transporting information in 5G /6G scenarios using many antennas. Techniques such as distributed MIMO require careful design concerning the functional splits and corresponding x-hauling strategies. UFPA has been investigating algorithms for efficient compression of channel state information (CSI), O-RAN-compliant quantization of IQ samples and related issues that involve both the radio signal and transport protocols. The goal in this proposal is to come up with optimized algorithms that can improve the x-hauling performance while achieving good performance with increased number of antennas.NTN is the main topic of the third WP. Within this research, UFPA will seek to thoroughly review the literature, understand the main issues and design simulation tools for investigations on x-hauling using NTNs. There are many specialized tools that can be used as part of a NTN simulation, such as Mathworks O-RAN [Zarrinkoub, 2022] that implements a 7.2 split with PCAP support, and "Satellite Communications" [Mathworks_a, 2022]. However, nowadays, there is still a lack of simulators that allow to conveniently investigate how NR can be optimized to deal with satellite links, for instance. One important deliverable of this proposal is a first recommendation of a set of tools to compose a simulation platform that can enable investigation of new protocols for x-hauling over NTN..
Situação: Em andamento; Natureza: Pesquisa.

6G Network Automation via Standardized Artificial Intelligence
Descrição: This project proposal targets the continuation of the UFA26 eDNA project. The goal is to further investigate network automation of 5G / 6G / B6G networks using machine learning and artificial intelligence (ML / AI) techniques through realistic simulations in virtual worlds and in an experimental setup. One distinctive feature of this proposal is the focus on aligning the recent advances of standardization bodies to promote AI applied to 3GPP networks. The following technological trends influence this proposal: a) end-to-end network automation, b) AI-based management of closed loops, c) intent-based management, d) data-driven architecture and e) distributed intelligence. Based on know-how accumulated over previous projects sponsored by Ericsson, the proposal emphasizes investigations on the physical layer (PHY) and medium access control layer (MAC), building upon simulations to generate data toenable evaluations of the proposed algorithms. Realistic simulation and digital twin implementations will be executed to enable assessing network decisions in virtual networks before being implemented in the target network. Another research activity is to further develop the Connected AI testbed being developed at UFPA, with emphasis on rApps executing AI algorithms to improve the SMO (Service Management and Orchestration) platform performance. More specifically, the research activities include new AI-based algorithms for intent-based radio resource scheduling, digital-twin techniques to reduce the overhead of procedures such as channel estimation and beam tracking, AI-based rApps development for service management and orchestration..
Situação: Concluído; Natureza: Pesquisa.

Integrantes: Diego de Azevedo Gomes - Integrante / ALDEBARO KLAUTAU - Coordenador / Francisco Carlos Bentes Frey Müller - Integrante.
