Projetos de pesquisa

2002 - Atual
Protótipo de um sistema de medição fasorial sincronizada (SMF) para sistemas de enegia elétrica (SEEs)
Descrição: O projeto MEDFASEE visa basicamente o desenvolvimento de um protótipo de sistema de medição fasorial sincronizada (SMF) para sistemas de energia elétrica (SEEs). Neste sistema, equipamentos de medição (PMUs) farão a leitura de medidas fasoriais de tensão e corrente em sítios remotos. Todas as (PMUs) enviarão continuamente os dados lidos para um concentrador (PDC), através de um sistema de transmissão de dados. O PDC fará a aquisição, o tratamento prévio e o armazenamento destes dados em uma base, a qual disponibilizará, de maneira concentrada, os dados relativos às diversas PMUs instaladas no sistema. Aplicações serão executadas em estações de trabalho específicas, e farão uso dos dados de medição fasorial concentrados no PDC. No âmbito do projeto MEDFASEE está prevista a construção de três PMUs e um PDC, os quais se comunicarão por rede ethernet. Duas aplicações estão previstas para operar fazendo uso dos dados fasoriais: a monitoração on-line de perturbações e a localização de defeitos permanentes em linhas de transmissão. além disso, prevêem-se estudos preliminares de outros conjuntos de aplicações potenciais que poderão fazer uso destes dados, principalmente aplicações na área de controle de SEEs..
