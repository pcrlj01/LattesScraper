Outras informações
Plano de trabalho de título: "Modelagem de Sistemas de Geração Fotovoltaica utilizando Redes Neurais para Estudos de fluxo de Carga Harmônico", pertencente ao projeto "PRO4821-2019 - Sistema Inteligente de Gestão Eficiente de Mobilidade Elétrica Multimodal". Neste plano de trabalho foram executadas técnicas de análise de dados e de modelagem por meio de redes neurais artificiais para a modelagem de dois sistemas fotovoltaicos, visando a análise do para estudos de fluxo de carga harmônico na rede na qual estão instalados.
