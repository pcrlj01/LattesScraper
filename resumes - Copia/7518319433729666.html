Desenvolvimento de metodologia para Avaliação de Alternativas equivalentes em Estudos de Expansão do Sistema de Transmissão: uma ótica probabilística
Descrição: O modelo multi-critério para avaliação de alternativas equivalentes em estudos de expansão do sistema e transmissão tem os seguintes objetivos: - Desenvolvimento de uma metodologia (multicritério) probabilística capaz de determinar o desempate e solução de interesses divergentes/conflitantes entre as partes envolvidas com o propósito de minimizar o tempo de tomada de decisão entre alternativas equivalentes e facilitar a identificação de melhor retorno à CTEEP, em estudos de expansão, contemplando o atendimento à regulação em vigor, avaliação dos aspectos técnicos e validação de dados disponíveis considerando os riscos, incertezas e avaliando probabilisticamente cada alternativa de solução. - Implementar a metodologia probabilística através de ferramenta computacional com interface amigável - Desenvolvimento de uma base de dados probabilístico, necessário para a aplicação da ferramenta computacional.
