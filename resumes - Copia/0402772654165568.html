Collaborative Engineering Environments - Laboratory for Advanced Collaboration (LAC)
Descrição: Projeto CEE/GIGA tem como principal objetivo a utilização da rede do Projeto GIGA como meio de transmissão para a viabilização dos chamados Ambientes Colaborativos de Engenharia (CEE - Collaborative Engineering Environment), especialmente voltados para a visualização e interação com dados remotos, utilizando técnicas de Realidade Virtual (RV) distribuída. A idéia é buscar uma solução efetiva para a colaboração entre os participantes de um grupo de trabalho (geograficamente distribuído) em grandes projetos de engenharia que necessitam da visualização de dados utilizando técnicas de realidade virtual. A meta do projeto é desenvolver um protótipo de CEE para a tele-colaboração em um ambiente de realidade virtual gerado a partir do modelo CAD.
