Nanotecnologia Empregada para o Desenvolvimento de Dissipadores de Calor (Edital FAPERJ 09/2013 - Processo E-26/111.068/2013)

Projeto certificado pelo(a) coordenador(a) Leandro Alcoforado Sphaier em 16/04/2014.
Descrição: O constante avanço tecnológico na indústria de eletrônicos, vem permitindo o desenvolvimento de componentes com mais alta capacidade e tamanhos cada vez menores. Por outro lado, a redução do tamanho destes componentes faz com que a densidade do aquecimento gerado, se torne maior, o que dificulta sua dissipação. Este problema é agravado quando se leva em consideração que diversos materiais empregados na indústria de eletrônicos são polímeros, os quais têm baixa condutividade térmica, e consequentemente baixa capacidade para dissipação de calor. Neste contexto, o objetivo principal deste projeto é o desenvolvimento de polímeros modificados com alta condutividade térmica para serem utilizados como dissipadores de calor. Os materiais desenvolvidos serão baseados em nanocompósitos de matriz polimérica. Estudos recentes mostram que a adição de pequenas frações de nanopartículas é suficiente para causar uma alteração notável nas propriedades térmicas e mecânicas efetivas de um material. O desenvolvimento deste objetivo naturalmente envolverá a caracterização, análise e simulação do comportamento térmico e mecânico de diferentes nanocompósitos poliméricos. Para tal, uma extensa análise experimental de propriedades térmicas e mecânicas será realizada. Ainda, modelos para estimar propriedades termofísicas efetivas de nanocompósitos serão desenvolvidos assim como simulações computacionais para comparação com os resultados experimentais obtidos serão realizadas. Ainda, uma importante parte do projeto será dedicada à análise da distribuição e dispersão de nanopartículas nos compósitos fabricados, uma vez que a literatura mostra que estas características têm grande influência sobre as propriedades macroscópicas efetivas. Esta análise será feita utilizando microscopia eletrônica, o que permitirá entender melhor a interação entre nanopartículas e matrizes, possibilitando que arranjos otimizados possam ser obtidos..
Situação: Concluído; Natureza: Pesquisa.

Nesse sentido, o presente projeto pretende desenvolver o estudo do PEAD (polietileno de alta densidade) reciclado. O foco principal são a simulação numérica e a caracterização termo-mecânica através da identificação das suas propriedades. Pretende-se estudar os processos de reciclagem de forma a otimizar o material reciclado para obtermos melhores propriedades..

Tecnologias Baseadas em Dessecantes Sólidos para Redução de Emissões de Gases de Efeito-Estufa. Processo E-26/112.640/2012.

Projeto certificado pelo(a) coordenador(a) Leandro Alcoforado Sphaier em 16/04/2014.
Descrição: Ciclos de resfriamento dessecantes constituem uma promissora alternativa para ciclos de ar-condicionado e refrigeração convencionais baseados em compressão de vapor, devido ao fato de utilizarem refrigerantes naturais como ar e água, envolvendo portanto nenhum risco ao ambiente. Com o objetivo de disseminar a utilização destes ciclos alternativos, este projeto de pesquisa propõe o desenvolvimento de uma ferramenta computacional para auxiliar no projeto e otimização de ciclos de resfriamento dessecantes. A metodologia empregada neste projeto consiste, primeiramente, na simulação de diferentes ciclos dessecantes, a fim de determinar as melhores configurações para diferentes condições ambientais. Isto será feito utilizando uma correlação algébrica para simular o desumidificador (muitas vezes utilizado na forma de uma a roda dessecante), que constitui o principal componente do ciclo. Em seguida, modelos mais elaborados serão utilizados para simular este componente, devido às limitações envolvidas na correlação algébrica usualmente utilizada para o cálculo de desumidificadores dessecantes. Entretanto, para não tornar as simulações muito demoradas, modelos diferenciais unidimensionais melhorados, obtidos a partir de modelos multi-dimensionais através da Técnica das Equações Integrais Acopladas serão utilizados. Por fim, correlações algébricas válidas para uma gama maior de casos também serão geradas e incorporadas no código. Estas deverão ser utilizadas sempre que válidas, deixando as simulações de modelos diferenciais apenas para os casos em que sejam realmente necessárias, tornando a ferramenta mais eficiente do ponto de vista computacional. Com este projeto será possível alavancar o desenvolvimento de ciclos alternativos, ecologicamente corretos, e totalmente sustentáveis, para refrigeração e ar-condicionado no Brasil..
