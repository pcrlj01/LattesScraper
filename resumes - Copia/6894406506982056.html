Outros controladores poderão ser estudados durante o projeto. Também será estudado o conversor para o processamento da energia gerada. Identificar os sensores apropriados para a determinação do rendimento de cada turbina de uma amostra a ser instrumentada; 2. Estabelecer as metodologias de medição e respectivos controles de qualidade dos resultados das medições; 3. Integrar as informações de cada conjunto de medição para o cálculo das grandezas hidráulicas e elétricas de cada turbina amostrada. Desenvolvimento de software de aquisição de dados, comunicação de dados e IHM (Interface Homem Máquina) relativa aos sensores implantados; 4. Desenvolver software com o objetivo de centralizar estas informações num centro de despacho de usinas utilizando a infraestrutura do Sistema de Supervisão e Controle da AES Tietê; 5. Propor as condições ideais de operação de cada usina com turbina instrumentada; 6. Calcular sistematicamente as condições ideais de despacho das usinas instrumentadas, com base na geração de energia..

Valorização de Serviços Ancilares

Objetiva também complementar o estudo anterior visando a valorização da disponibilidade para controle de frequência e reserva girante/fria..
